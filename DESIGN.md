# Design System - Portfolio

## Product Context
- **What this is:** A personal portfolio for Yujun Zhou, focused on data science, AI product building, applied economics, selected projects, and published research.
- **Project type:** Editorial personal site with compact project and publication cards.

## Aesthetic Direction
- **Direction:** Crisp personal AI studio, close to the reference feel of nanawang.dev.
- **Mood:** Clear, calm, credible, and lightweight. The page should feel like a sharp builder with research depth, not a generic tech landing page.

## Typography
- **Display/Hero:** Source Sans 3, heavy weights.
- **Body/UI:** Source Sans 3, regular to semibold weights.
- **Rationale:** The reference site is clean, sans-serif, and direct. One family keeps the page crisp and avoids academic heaviness.
- **Scale:**
  - Hero name: `4.7rem` desktop, `3.35rem` tablet, `2.65rem` mobile.
  - Section headings: `2.35rem` desktop, `2rem` tablet, `1.65rem` mobile.
  - Role line: `1rem`, uppercase, heavy.
  - Body text: `1rem` base, intro copy `1.05rem`.
  - Card titles: `1.08rem` to `1.22rem`.

## Color
- **Approach:** Restrained blue-green system with rare accent use.
- **Primary:** `#2e7d91`
- **Primary dark:** `#17495a`
- **Accent:** `#2e7d91`
- **Ink:** `#1f343b`
- **Muted text:** `#60757c`
- **Background:** `#f7fbfc`
- **Panel:** `#eef7f9`
- **Border:** `#dbe9ee`

## Spacing
- **Density:** Comfortable but compact.
- **Rule:** Use generous whitespace for section separation, tighter padding inside cards so the page reads quickly.
- **Cards:** `18px` to `24px` padding.
- **Sections:** `68px` desktop vertical padding, `52px` mobile.

## Layout
- **Approach:** Grid-disciplined.
- **Max content width:** `1180px`.
- **Hero:** Text on the left, portrait on the right, stacked centered layout on mobile.
- **Cards:** 4px radius, subtle shadow, restrained hover motion.

## Motion
- **Approach:** Minimal-functional.
- **Use only:** Small hover translations and color state changes.
